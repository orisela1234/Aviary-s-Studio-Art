# הסטודיו של אביה · Aviary's Studio Art

דף נחיתה לסטודיו לסדנאות יצירה ואומנות: חוג שבועי, סדנאות לאירועים וסדנאות פרטיות.

אתר סטטי, בלי תלויות ובלי שלב build. כל האיורים מצוירים בקוד (Canvas) כצבעי מים גנרטיביים, כך שאין קבצי תמונה.

## הרצה מקומית

```bash
python3 -m http.server 8000
# ואז לפתוח http://localhost:8000
```

אפשר גם פשוט לפתוח את `index.html` בדפדפן.

## מבנה

```
index.html            כל התוכן והטקסטים
assets/css/styles.css עיצוב: פלטת הצבעים והפונטים מוגדרים בראש הקובץ (:root)
assets/js/main.js     צבעי המים, הדף שאפשר לצייר עליו, אנימציות הגלילה והטופס
assets/favicon.svg    אייקון הלשונית
```

## לפני העלאה לאוויר

בראש `assets/js/main.js` יש אובייקט `STUDIO`. צריך לעדכן בו:

- `whatsapp`: מספר הוואטסאפ בפורמט בינלאומי, ספרות בלבד (למשל `972521234567`). הטופס מרכיב הודעה ופותח איתה את וואטסאפ.
- `instagram`: הקישור המלא לפרופיל.

טקסטים שנכתבו כטיוטה וכדאי לאשר מול אביה: הביוגרפיה ב״קצת עליי״, התשובות בשאלות הנפוצות, רשימת הטכניקות, וימי השבוע שמסומנים באיור של החוג השבועי (ב׳ ו־ה׳ הם דוגמה בלבד).

## נגישות וביצועים

- עברית מימין לשמאל, ניווט מקלדת, קישור ״דילוג לתוכן״ ומיקוד גלוי.
- מי שהגדיר במערכת ״הפחתת תנועה״ מקבל את האתר בלי אנימציות גלילה.
- האיורים מצוירים רק כשהם מתקרבים למסך.
